# Memory — Reforço IA Kids

## Decisões Arquiteturais
- Next.js 15 App Router escolhido por SSR, RSC e ecosystem
- Supabase escolhido por auth nativo, RLS, real-time e custo acessível
- Claude API para tutoria: melhor raciocínio lógico e instrução pedagógica
- Nano Banana para imagens: integração simples, qualidade adequada para edu
- A2UI para componentes interativos educacionais
- Stripe + Asaas: cobertura internacional + métodos brasileiros (PIX, boleto)

## Origens de Estratégia
- Squad "sales-funnel-masters" definiu pricing tiers e funil de conversão
- Squad "adaptive-tutor-k12" definiu modelo pedagógico e algoritmo adaptativo
- Pesquisa em research/ validou dores dos pais e disposição de pagamento

## Padrões Confirmados
- Pais classe B/C priorizam custo-benefício sobre marca
- Crianças engajam mais com conteúdo visual e gamificado
- WhatsApp é canal preferido dos pais para relatórios
